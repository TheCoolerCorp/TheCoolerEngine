# TheCoolerEngine

TheCoolerEngine is a basic game engine made in 3 months with a team of 3 peoples. It use Vulkan as graphics API and imgui for the UI. 

## Features
Physically based rendering (PBR)
Material editor (to change albedo, roughness etc... with either a texture or a value)
Entity Component System (ECS)
